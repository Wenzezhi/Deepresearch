# 设计文档：报告质检门禁（Report Quality Gate）

> 版本：v1.0（已实现）｜独立模块，不改动研究主流程、导出与本地文献功能

## 1. 定位

研究生成已经解决了"能不能出报告"，本功能解决"**这份报告能不能交付**"。

产品形态：报告阅读区右上角「质检」入口 → 右侧滑出面板，给出评分、问题清单、来源清单与质检单；可选**在原文中标记问题位置**（默认关闭，打开才在报告里加高亮与角标，关闭即完全恢复原样）。

## 2. 功能范围（v1）

| 能力 | 说明 |
|---|---|
| 引用可核验 | 报告里的链接是否真的来自本次检索；疑似编造单独列出 |
| 来源覆盖 | 长章节无来源、检索到但未被引用的来源 |
| 结构完整 | 缺结论段、缺局限说明、空章节、标题层级跳跃、报告过短 |
| 来源质量 | 来源过少、单一域名占比过高、任务零来源、只有本地来源 |
| 交付规范 | 缺参考文献段、参考文献段为空、链接写法混杂、链接无文字 |
| 评分与分级 | 100 分制，A/B/C/D 四档，扣分权重固定可解释 |
| 质检单 | 一键生成可附在报告后的 markdown（指标 + 问题 + 建议） |
| 参考文献核验清单 | 列出报告里**全部**参考文献条目及其状态（正常 / 未核验 / 正文未引用 / 缺少条目），可点击跳转 |
| 规范参考文献表 | 按首次引用排序、去重、编号；支持 plain / gbt7714-lite |
| 原文标记开关 | 打开：高亮章节/段落并加角标；关闭：移除全部标记，DOM 复原 |

**明确不做**：不改写报告正文、不生成 Word、不新增数据表、不访问网络、不调用模型。

## 3. 数据来源（只读）

- `events` 中最后一次 `final_report` 的 `report`（遇到 `reset` 清空）
- `events` 中 `sources` 事件的 `latest_sources`，以及任务快照里的 `sources_summary`
  （格式实测为 `* 标题 : URL`；本地文献为 `local://documents/{id}`）
- 任务快照（`ResearchJobs.snapshot`）提供 task_id ↔ 标题
- `documents` 表提供本地文献 id 集合，用于判断"引用的本地文献是否已被删除"

不写库、不写文件；同一 run 连续调用结果一致（`generated_at` 除外）。

## 4. 接口

```
GET  /quality/audit/{run_id}
  → { run_id, topic, report_available, metrics{...}, score, grade,
      issues[], issue_summary{}, sources[], generated_at }
POST /quality/report  { run_id, style: "plain"|"gbt7714-lite", include_uncited }
  → { markdown, references_markdown, score, grade }
```

错误：`404` run 不存在；`422` style 非法。

## 5. 检查规则要点

- 引用抽取四种形态：markdown 链接、短横线来源行（`- 标题 — URL`）、裸 URL、`local://`；
  代码块内的 URL 与标题一律忽略。
- URL 归一化：去 fragment、去追踪参数（`utm_*`、`fbclid` 等）、host 小写去 `www.`、
  去尾斜杠、`http` 与 `https` 等价；`local://documents/{id}` 归一为 `local:{id}`。
- 引用形态（v1.3）：支持 markdown 链接、短横线来源行、裸 URL、`local://` 本地文献，
  以及**编号引用** `[n]` + 文末 `[n] 标题. 域名. URL` 参考文献表。
- 编号引用校验（v1.3）：
  - `unresolved_citation_number`：正文引用了 `[n]`，但参考文献表没有该编号；
  - `uncited_reference`：参考文献表有该条目，但正文从未引用；
  - 编号引用 `[1]` 被多次使用属于规范写法，**不**计入重复引用。
- 长章节判定：正文 ≥ 400 字、含结论/数据类表述、且该章节内零**行内**引用；
  标题层级 1 不计入空章节。
- 行内引用语义（v1.1）：报告只把来源堆在文末、正文零行内引用时，只报一条
  「全文无行内引用」，不再对每个章节各报一次，避免刷屏与误伤。
- 引用可追溯（v1.1）：每条引用输出 `section / line / snippet`，
  并标注位于正文还是参考文献段；问题项也带行号，可跳转到原文。
- 评分扣分上限按类型封顶，保证"问题很多"不会把分数直接打到 0 而无从解释。

## 6. 前端交互与开关

- 入口：`ResearchDocument.vue` 报告块 actions 槽内两个按钮（唯一接线点，2 行）：
  - **「质检」**：打开右侧面板（评分、指标、问题/来源/引用位置/质检单四个 tab）；
  - **「标记」**：独立开关原文标记，不依赖面板开合。
- **原文标记**（v1.1）：
  - 默认关闭，状态按 run 记在 `localStorage`，刷新或切回仍保持；
  - 打开：给问题所在标题/段落加 `rqg-flagged` 并插入严重级角标，
    按钮显示"标记 N"；
  - 关闭：移除全部类与角标，报告 DOM 复原；
  - **关闭质检面板不会清除标记**（面板内也明确提示）；
  - 报告重新生成后按当前开关状态自动重标。
- 标记图层（v1.3）：
  - 只做**只读装饰**：在具体链接/句子后插入上标角标，引用用 `[n]`、问题用严重级符号；
  - 标注方式三选一（面板内切换、按浏览器持久化）：`角标` / `角标+下划线` / `角标+底色`；
  - 关闭开关即移除全部角标、类与包裹节点，报告 DOM 恢复原始渲染；
  - **不会插入或改写报告里的任何链接与文字**。
- **引用位置 tab**：逐条列出引用（句子、章节、行号、正文/参考文献段、编号），
  点击定位；「来源」tab 每条来源可定位到它的首次引用位置。
- **定位粒度（v1.2）**：
  - 链接级：按 URL 精确匹配正文中的 `<a>`，直接高亮该链接并滚动居中；
  - 句子级：后端为每条引用计算"可见句子"（去掉 markdown 标记），
    定位时在文本节点中把该句包成 span 高亮；
  - 章节级：仅作为兜底（如"全文无行内引用"这类整体问题）。
- 面板宽 440px，可随时关闭；因标记独立，用户可"关面板看原文"。
- 质检单 tab：生成后可预览、复制 Markdown（不改动报告本身）。

## 11. 变更记录

- v1.0：引用审计 → 报告质检门禁；评分/分级、质检单、规范参考文献表、原文标记开关。
- v1.1（按验收反馈优化）：
  - 修复"关闭边栏标记消失"：标记改为工具栏独立开关，按 run 持久化到 localStorage，
    关闭面板不影响标记；
  - 收紧"无来源章节"：正文零行内引用时只报一条「全文无行内引用」，
    章节级判定要求 ≥400 字且含结论/数据类表述，避免刷屏；
  - 增加"引用可追溯"：新增引用位置清单（章节/行号/原文片段/正文或参考文献段），
    新增「引用位置」tab，来源列表可定位到首次引用位置；
  - 新增确定性演示工具 `tools/demo/`，演示数据由真实研究流程生成。

- v1.2（定位粒度细化）：
  - 后端为每条引用计算可见句子 `quote`（去 markdown 标记），并给无来源章节
    附带代表性句子，供前端精确定位；
  - 前端定位优先级：URL 匹配 `<a>` 链接 → 句子文本包裹高亮 → 段落 → 标题兜底；
  - 标记图层同步升级：链接级高亮 + 句子级包裹，关闭时完整复原 DOM。

- v1.3（规范引用形式）：
  - 支持编号引用 `[n]` 与编号参考文献表，校验编号缺失、文献未引用；
  - 编号引用重复使用不再误报为重复引用；
  - 标注改为上标角标（引用 `[n]` / 问题严重级），提供三种标注方式；
  - 明确：质检**不插入、不修改**报告里的链接与文字，所有标注都是只读装饰；
  - 演示报告改为规范编号引用风格（正文无裸链接，URL 只出现在参考文献表）。

- v1.4（参考文献清单与报告洁净）：
  - 新增 `references[]` 数据与「参考文献」tab：列出全部条目与状态，点击可跳转；
    缺少条目的编号也能列出并跳回正文对应引用；
  - 质检单新增「参考文献核验」表格；
  - 演示报告移除"另有一条编号在本表中不存在"这类质检口吻的文字，
    问题只出现在质检结果里，报告本身保持正常行文。
